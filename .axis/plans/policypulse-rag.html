Approach · three ingestion options, two retrieval modes

Breadcrumb preprocessing with function-call retrieval

The shaping dialogue chose breadcrumb preprocessing. Planning added one refinement: on Gemini, the stock tool runs retrieval server-side and leaves no tool call to test or show.

Left unbuilt, and what would bring it back

  • Live eval in CI: once the agent changes weekly; it needs Workload Identity Federation and a judge budget.

  • Deployment beyond adk web: out of scope for this sign-off.

Risks · what could block sign-off

Open risks and their checks

API details were read from the published 2.14.1 and 2.10.0 packages. Service availability could not be checked from the docs in this session, so each such item has a runbook preflight.

  • warning Gemini 2.5 Flash may be retired or absent in the region. ADK 2.14.1 already defaults to gemini-3.5-flash. A one-request preflight checks it; POLICYPULSE_MODEL switches it.
  • warning RAG Engine region may be restricted. The preflight lists corpora in us-east4; europe-west4 is the fallback.
  • warning The Q10 facts may not be in the Road Safety PDF. The render step checks; if they are absent, the reviewer decides on the expected answer.
  • check_circle The subclass depends on ADK internals. The version is pinned, and a characterization test fails first on any upgrade that changes the parent tool.
  • check_circle A splitter could misread real PDF text. The contract gate stops the run before upload, and each fix starts with a failing fixture case.
  • warning The API spec belongs to another system. It stays gitignored unless its owners agree to a committed copy; SOURCES.md records its hash.
  • warning Running costs. Each full eval makes 13 conversations plus judge calls, times the run count; the managed vector database may bill while provisioned.
  • check_circle Judge noise could flip a case. Three judge samples, three runs per case, and a 2-of-3 pass rule absorb it.

Open questions from the dialogue

  • File name and format of the Customer Registration API spec: .md or .pdf.

Definition of done · reviewer sign-off

What the reviewer checks

Every item is observable from a fresh clone that follows the runbook.

  • radio_button_unchecked Repeatable ingestion: the second run uploads nothing and leaves .env byte-identical.
  • radio_button_unchecked Recall: each expected label for Q1 to Q12 appears in the top 10.
  • radio_button_unchecked 13 of 13: adk eval passes every case over three runs, with citations.
  • radio_button_unchecked Refusal: Q13 returns exactly the refusal sentence, with no number.
  • radio_button_unchecked Demo: adk web shows the tool calls and citations for Q1 to Q13.
  • radio_button_unchecked Diagram: editable draw.io and Mermaid files, with the Mermaid embedded in the README.
  • radio_button_unchecked Unit TDD: test commits precede implementation commits; CI is green without GCP credentials.
  • radio_button_unchecked Eval TDD: the eval set predates the agent; eval/runs/ shows the red baseline and the green final run.
